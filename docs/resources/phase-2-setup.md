# Фаза 2 — QR бележки (setup)

## Какво е готово в кода

- Parser по НАП формат (`FMIN*номер*дата*час*сума`)
- Fallback: поставяне на QR текст в браузър
- Native сканер: `@capacitor-mlkit/barcode-scanning` (Android)
- Дедуп преди запис + unique index в БД

Няма нова SQL migration — колоните `fiscal_memory_no` / `receipt_no` са от Фаза 1.

## Тест в браузър (без телефон)

1. `npm run dev` → Разходи
2. Постави примерен текст:
   `01234567*0000000123456789*2017-05-20*12:45:56*45.89`
3. **Попълни от текста** → сума/дата се попълват
4. Избери категория → Добави
5. Повтори същия QR → трябва да видиш грешка за дубликат

## Тест на реален телефон (задължително за дипломната)

```bash
npm run cap:sync
npm run cap:open
```

1. Стартирай app-а на устройство (не емулатор за камера)
2. **Сканирай QR** от реална бележка
3. Потвърди сума/дата, избери категория, запиши
4. Сканирай същата бележка отново → дубликат се отхвърля
5. Запиши суровите QR низове в `docs/resources/qr-receipt-format.md`

## Verify критерии

- [ ] Parser попълва сума и дата от валиден QR
- [ ] Невалиден низ показва ясно съобщение
- [ ] Дубликат (същи ФП + номер) се блокира
- [ ] Реални бележки от ≥2 магазина работят на телефон
- [ ] При неуспех остава ръчното въвеждане
