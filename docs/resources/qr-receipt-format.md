# QR формат на български касови бележки

Източник: Наредба № Н-18, приложение № 18а (ДВ / НАП).

## Структура

Пет полета, разделени със `*`:

```
<FMIN или IASUTDID>*<номер на документ>*<ГГГГ-ММ-ДД>*<ЧЧ:ММ:СС>*<сума>
```

Пример:

```
01234567*0000000123456789*2017-05-20*12:45:56*45.89
```

| Поле | Значение |
|------|----------|
| 1 | Номер на фискалната памет (FMIN) или ID на ИАСУТД |
| 2 | Номер на документа / бележката |
| 3 | Дата |
| 4 | Час |
| 5 | Обща сума |

## В приложението

- Parser: `src/features/receipts/parseQr.js`
- Дедуп по `(fiscal_memory_no, receipt_no)` — уникален индекс в БД
- Поток: сканиране/paste → попълва сума + дата → потребителят избира категория → запис
