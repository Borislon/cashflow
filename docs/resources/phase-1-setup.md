# Фаза 1 — разходи (setup)

## 1. SQL migration

В Supabase → SQL Editor изпълни:

`supabase/migrations/202603280002_categories_expenses.sql`

(след като `profiles` вече е пусната)

Създава:
- `categories` + seed (Храна, Транспорт, …)
- `expenses` + RLS (засега само собственикът вижда своите)
- колони за бъдещ QR дедуп и семеен scope

## 2. Тест в приложението

```bash
npm run dev
```

1. Влез в акаунта
2. Отвори **Разходи**
3. Добави разход (сума, дата, категория, бележка)
4. Филтрирай по период / категория
5. Редактирай и изтрий

## Verify критерии

- [ ] Списък с разходи след refresh / друг device със същия акаунт
- [ ] Филтър по период и категория
- [ ] Редакция и изтриване
- [ ] Чужд акаунт **не** вижда твоите разходи
